# Dashboard - документация

`Dashboard` — это домашняя страница с карточками объектов и переключаемыми режимами группировки.

[English documentation](index.md)

## Где находится

- Страница для пользователя: `/index`
- Страница администратора: `Администрирование -> Dashboard`

## Основные возможности

- отображение карточек объектов;
- переключение режима группировки;
- сохранение выбранной группы для каждого пользователя;
- обновление карточек и групп в реальном времени.

> [!IMPORTANT]
> Отображаются только объекты, у которых есть шаблон отображения (`render/template`).

## Пользовательский интерфейс (`/index`)

Документ описывает, что видит обычный пользователь на странице Dashboard.

### Элементы страницы

- лента кнопок группировки (если доступно больше одной группы);
- блоки групп с заголовком и количеством объектов;
- карточки объектов внутри групп;
- сворачивание/разворачивание групп.

### Как пользоваться

1. Откройте `/index`.
2. Выберите нужную группу в верхней ленте.
3. Просматривайте карточки объектов в выбранном режиме.
4. Сворачивайте редко используемые группы.

### Что запоминается

- выбранный режим группировки сохраняется для пользователя;
- состояние свернутости групп сохраняется в браузере (`localStorage`).

### Важные ограничения

- без `template/render` объект не будет показан;
- если режим группировки отключен администратором, автоматически выбирается первый доступный режим.

## Админ-настройки

Документ описывает настройки в `Администрирование -> Dashboard`.

### Общие настройки

| Поле | Что делает |
| --- | --- |
| `Включить группировку по классу` | Добавляет режим группировки по классу |
| `Скрыть приветствие` | Скрывает баннер приветствия на `/index` |
| `Скрыть опцию "Без группировки"` | Убирает режим без группировки |

### Пользовательские группы (`Настройки пользовательских групп`)

| Поле | Назначение | Пример |
| --- | --- | --- |
| `Имя группы` | Имя группы в интерфейсе | `Комнаты` |
| `Icon` | CSS-класс иконки | `fas fa-door-open` |
| `Имя свойства` | Свойство объекта для группировки | `room` |
| `Свойство объекта` | Свойство связанного объекта | `name` |
| `Подстановки значений` | Подстановка названий групп | `0-Выкл,1-Вкл` |
| `Показывать объекты с неопределенным значением свойства` | Показывать группу `Undefined` | Вкл/Выкл |

### Быстрая настройка новой группы

1. Нажмите `Добавить группу`.
2. Заполните минимум `Имя группы` и `Имя свойства`.
3. При необходимости задайте `Icon`, `Свойство объекта`, `Подстановки значений`.
4. Нажмите `Save` (кнопка в интерфейсе локализуется как `Сохранить`).

## Группировка и правила отображения

Документ объясняет, как Dashboard формирует группы.

### 1. Без группировки (`none`)

Все отображаемые объекты попадают в один список.

### 2. По классу (`class`)

Объекты группируются по первому родителю (классу).
Заголовок берется из описания класса или имени класса.

### 3. Пользовательская группа (`custom`)

Группировка идет по полю `Имя свойства`.

- если `Свойство объекта` пустое: берется значение свойства текущего объекта;
- если `Свойство объекта` заполнено: значение `Имя свойства` трактуется как имя другого объекта и берется его свойство.

### Правило отображения объектов

Объект попадает в Dashboard только если `obj.render()` возвращает шаблон.

### Обработка пустого значения

Если у свойства нет значения:

- при включенной опции `Показывать объекты с неопределенным значением свойства`: объект идет в группу `Undefined`;
- при выключенном режиме: объект скрывается из текущего представления.

### Подстановка заголовков (`Подстановки значений`)

Формат:

```text
ключ-значение,ключ-значение
```

Пример:

```text
0-Выключено,1-Включено
```

## Поведение в реальном времени

Dashboard поддерживает реактивное обновление без полной перезагрузки страницы.

### Что обновляется автоматически

- содержимое карточек объектов (события изменения объекта);
- перемещение объекта между группами при изменении свойства группировки;
- набор подписок на объекты и свойства при переключении режима.

### Как это работает на уровне интерфейса

- клиент подписывается на нужные объекты и свойства через socket;
- при смене группы выполняется обновление данных через JSON endpoint;
- для DOM-обновлений используется безопасная перерисовка HTML карточек.

### Что важно учитывать

- если используется `Свойство объекта`, для вычисления новой группы выполняется дополнительный запрос;
- при ошибке обновления интерфейс может выполнить fallback-перезагрузку страницы.

## Диагностика и частые проблемы

### Не отображаются ожидаемые объекты

Проверьте:

- у объекта есть `template/render`;
- объект реально существует в `objects_storage`;
- в выбранном режиме объект не отфильтрован логикой группировки.

### Не появляется нужная группа

Проверьте:

- группа сохранена в `Администрирование -> Dashboard`;
- заполнены `Имя группы` и `Имя свойства`;
- режим не скрыт настройками (`Скрыть опцию "Без группировки"`, выключенный `Включить группировку по классу`).

### Объект не попадает в пользовательскую группу

Проверьте:

- корректность `Имя свойства`;
- корректность `Свойство объекта` (если используется связанный объект);
- значение свойства действительно не пустое;
- включена ли опция `Показывать объекты с неопределенным значением свойства`.

### Непонятные названия групп

Добавьте `Подстановки значений`, например:

```text
0-Выключено,1-Включено
```

### После изменения настроек отображение не изменилось

- нажмите `Save` в админке;
- переключите группу на `/index`;
- обновите страницу браузера;
- проверьте логи Dashboard при валидационных ошибках формы.
